# Images du site

Les schémas bilingues sont dans `assets/fr/` et `assets/en/` : système et environnement, transformations, cycle de Hess et calorimètre zinc/cuivre. Ils partagent une géométrie commune, produite par `build-diagrams.py` ; seules les légendes changent.

Les trois illustrations verre/bouteille/thermos et le bandeau CC BY-NC-ND sont conservés dans `assets/images/`.

Les neuf anciennes images PNG qui ne sont plus appelées par le site ont été retirées de l’archive. Les animations du piston et du chauffage sont dessinées par le code du site.
