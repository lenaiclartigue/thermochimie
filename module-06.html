Enthalpies de formation

Écrire une réaction de formation et calculer une enthalpie de réaction.

Comprendre la notion

L’enthalpie standard de formation correspond à la formation de une mole d’un composé dans son état standard à partir des éléments dans leurs états standard de référence, à la même température.

L’enthalpie standard de formation d’un élément dans son état de référence vaut zéro par convention. Cela ne signifie pas que toutes ses formes ont une enthalpie de formation nulle : le graphite et le diamant, par exemple, doivent être distingués.

Pour une réaction équilibrée, additionnez les enthalpies de formation des produits pondérées par leurs coefficients, puis soustrayez la somme correspondante pour les réactifs. Précisez les phases.

Équilibrer et préciser les états

Le calcul thermochimique commence par une équation équilibrée. Une combustion donnant H₂O(l) n’a pas la même enthalpie qu’une combustion donnant H₂O(g). L’enthalpie de formation d’un composé est associée à un état physique et à une température.

Exemple supplémentaire : les données du cours pour 3 C₂H₂(g) → C₆H₆(g) conduisent à 82,9 − 3 × 226,7 = −597,2 kJ·mol⁻¹. Pour ξ = 0,10 mol, la variation totale vaut environ −59,72 kJ.

ΔrH° = Σproduitsν ΔfH° − Σréactifsν ΔfH°

Un exemple commenté

Pour C₂H₄(g) + H₂(g) → C₂H₆(g), les données du TD donnent −84,67 − 52,28 − 0 = −136,95 kJ·mol⁻¹.

Avant de regarder la correction

Écrivez la réaction de formation de H₂O(l) à 298 K.

Afficher le raisonnement

H₂(g) + ½ O₂(g) → H₂O(l). Le coefficient de l’eau est 1.

Application numérique

C₂H₄(g) + H₂(g) → C₂H₆(g). ΔfH° : C₂H₄ = 52,28 ; C₂H₆ = −84,67 ; H₂ = 0 kJ·mol⁻¹. Calculez ΔrH°.

kJ·mol⁻¹

Un indice

Produits moins réactifs, avec leurs coefficients.

La résolution

ΔrH° = −84,67 − 52,28 = −136,95 kJ·mol⁻¹.
