Références des données numériques

Les données d’un énoncé (masses, quantités, températures initiales et finales) sont imposées. Pour les propriétés physiques, les références ci-dessous distinguent une source identifiée d’une référence de comparaison. Une référence de comparaison ne certifie pas la provenance exacte des chiffres retenus.

Eau : chauffage et changements d’état

Cₚ,ₘ : glace 37,62 ; liquide 75,3 ; vapeur 33,58 J·mol⁻¹·K⁻¹. ΔfusH = 6,00 et ΔvapH = 40,7 kJ·mol⁻¹. c = 4,18 J·g⁻¹·K⁻¹ ; Lfus = 334 J·g⁻¹.

NIST Chemistry WebBook — eau

Valeurs constantes retenues pour les calculs. La fiche NIST fournit des données dépendant de la température ; elle ne constitue pas la source exacte de toutes ces constantes. La provenance exacte de 37,62 et 33,58 reste à documenter. Les repères 0 °C et 100 °C sont approchés pour une pression voisine de la pression atmosphérique.

Enthalpies de formation

CO₂(g) : −394 ; H₂O(l) : −286 ; C₆H₆(g) : 82,9 ; C₂H₂(g) : 226,7 ; C₂H₄(g) : 52,28 ; C₂H₆(g) : −84,67 kJ·mol⁻¹.

CO₂, eau, benzène, acétylène, éthylène, éthane

Références de comparaison : NIST Chemistry WebBook. Les valeurs sont conservées pour les exemples ; les compilations peuvent présenter plusieurs mesures et évaluations. CO₂ et H₂O sont arrondies à l’unité. La source exacte des autres chiffres retenus reste à confirmer.

Enthalpies de dissociation

H–H : 436 ; Cl–Cl : 243 ; H–Cl : 432 kJ·mol⁻¹.

OpenStax, Chemistry 2e, §7.5

Valeurs du tableau des énergies moyennes de liaison pour des espèces gazeuses.

Températures de changement d’état

Cu : 1084,62 / 2562 °C ; Pb : 327,46 / 1748 °C ; Hg : −38,83 / 356,73 °C (fusion puis vaporisation).

copper, lead, mercury

Référence de comparaison : Royal Society of Chemistry. Repères arrondis conservés dans l’animation. Attention : la RSC indique 2560 °C pour l’ébullition du cuivre ; elle ne justifie donc pas exactement la valeur 2562 °C affichée.

Capacité thermique du zinc

cZn = 0,380 J·g⁻¹·K⁻¹.

NIST Chemistry WebBook — zinc

Constante imposée dans l’exemple. La fiche NIST est une référence de comparaison ; l’origine exacte de 0,380 reste à documenter.

Données des cycles de Hess

Propane : −2220 kJ·mol⁻¹. Hydrazine : enthalpies des équations 2 à 5 = 46,19 ; 58,04 ; 142,80 ; −551,36 kJ·mol⁻¹.

NIST — propane ; NIST — hydrazine ; NIST — ammoniac

Données imposées pour ces exemples. La source bibliographique exacte de la série hydrazine n’a pas été identifiée. Ces références permettent une comparaison, sans attribuer cette série de nombres au NIST.

Constante des gaz parfaits

R ≈ 8,314 J·mol⁻¹·K⁻¹.

NIST — constante molaire des gaz

Valeur arrondie. Les masses molaires simplifiées servent aux conversions des exemples.
