References for numerical data

Problem data (masses, amounts, initial and final temperatures) are given values. For physical properties, the references below distinguish identified sources from comparison references. A comparison reference does not certify the exact origin of the values used.

Water: heating and phase transitions

Cₚ,ₘ: ice 37.62; liquid 75.3; vapour 33.58 J·mol⁻¹·K⁻¹. ΔfusH = 6.00 and ΔvapH = 40.7 kJ·mol⁻¹. c = 4.18 J·g⁻¹·K⁻¹; Lfus = 334 J·g⁻¹.

NIST Chemistry WebBook — water

Constant values used in the calculations. NIST provides temperature-dependent data; it is not the exact source of all these constants. The exact origins of 37.62 and 33.58 remain to be documented. The 0 °C and 100 °C reference temperatures are approximate for near-atmospheric pressure.
